# Chat web DINNERS

## Configuracion de Groq

El flujo principal funciona sin depender de una clave expuesta en el navegador. Si se desea usar Groq como capa de redaccion adicional, configurar `GROQ_API_KEY` en el entorno del servidor y mantener la clave fuera de Git.

## Flujo de venta

1. Informa y descubre el interes del cliente.
2. Responde una objecion de forma breve y respetuosa.
3. Si el cliente rechaza claramente, cierra sin insistir.
4. Solo solicita DNI, celular y correo despues de una intencion explicita de solicitar la tarjeta.
