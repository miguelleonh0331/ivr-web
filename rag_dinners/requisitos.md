# DINNERS - Requisitos y Proceso de Solicitud

## Requisitos Generales

### Personas Naturales

| Requisito | Detalle |
|-----------|---------|
| **Edad** | 21 - 70 años |
| **DNI vigente** | Con domicilio actualizado |
| **Ingreso mínimo** | S/ 2,500 mensual (Classic), S/ 5,000 (Gold), S/ 12,000 (Platinum), S/ 25,000 (Black) |
| **Antigüedad laboral** | Mínimo 6 meses en empleo actual |
| **Historial crediticio** | No estar en SIS/Infocorp con deuda vencida > S/ 1,000 |
| **Domicilio** | Comprobable (recibo de luz, agua, teléfono) |
| **Teléfono** | Celular y fijo (opcional) |
| **Correo electrónico** | Activo |

### Personas Jurídicas

| Requisito | Detalle |
|-----------|---------|
| **RUC vigente** | Activo y habido |
| **Representante legal** | Con DNI vigente |
| **Vigencia de poderes** | Actualizada |
| **Estados financieros** | Últimos 2 años |
| **Declaración de renta** | Últimos 2 años |
| **Patrimonio empresa** | Mínimo S/ 100,000 |

## Documentación Requerida

### Empleados Dependientes

1. DNI (frente y reverso)
2. Boleta de pago últimos 3 meses
3. Constancia de trabajo (máximo 3 meses de antigüedad)
4. Recibo de servicio (luz, agua, teléfono) último mes

### Empleados Independientes

1. DNI (frente y reverso)
2. Recibo por honorarios últimos 6 meses
3. Declaración de renta último año
4. Ficha RUC (si aplica)
5. Recibo de servicio último mes

### Pensionistas

1. DNI (frente y reverso)
2. Última boleta de pensión
3. Constancia de pensionista
4. Recibo de servicio último mes

## Proceso de Solicitud

### Paso 1: Pre-evaluación Online (2 minutos)

- Ingresar a www.dinners.pe/solicitar
- Completar formulario básico (nombre, DNI, celular, ingreso)
- Respuesta inmediata: pre-aprobado / en evaluación / no califica

### Paso 2: Documentación (5 minutos)

- Subir documentos por web o app
- Fotos desde celular (calidad mínima 300 DPI)
- Validación OCR automática

### Paso 3: Evaluación Crediticia (24-48 horas)

- Consulta a Infocorp/SIS
- Verificación de ingresos
- Análisis de historial crediticio
- Score DINNERS (0 - 1,000)

### Paso 4: Respuesta Final

| Resultado | Tiempo | Próximo paso |
|-----------|--------|--------------|
| **Aprobado** | 24-48h | Recibir tarjeta en 3-5 días hábiles |
| **Condicionado** | 48-72h | Solicitar documentación adicional |
| **Rechazado** | Inmediato | Reintentar en 6 meses |

## Score DINNERS

| Rango | Clasificación | Probabilidad de Aprobación |
|-------|---------------|---------------------------|
| 800 - 1,000 | Excelente | 95% |
| 650 - 799 | Bueno | 80% |
| 500 - 649 | Regular | 50% |
| 350 - 499 | Bajo | 20% |
| 0 - 349 | Muy bajo | 5% |

**Factores que afectan el score**:
- Historial de pagos (40%)
- Ingreso vs. compromisos (25%)
- Antigüedad crediticia (15%)
- Tipo de empleo (10%)
- Uso de productos financieros (10%)
